## ⚡ Introduction

An API server built using **Express.js**

## 🐳 Features

- User authentication (Login)
- Middleware for error handling and request authentication

## 🚀 Development
```bash
# clone
git clone https://github.com/devnoellin/express-api.git

# enter the project directory
cd express-api

# install dependencies
npm install

# Create a .env file from the .env.example file, and set up the local environment.
cp .env.example .env

# start the service
npm run dev
```

## 🔍 Git commit specification reference

- `feature` add new functions
